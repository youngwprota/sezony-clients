# Sезоны — план разработки

Своя система онлайн-записи для салона «Sезоны» (Минск, цены в BYN) вместо YCLIENTS.

**Рамки.** Только работа с клиентами и записями. Кассы, оплата, зарплата, склад, бонусы и
сертификаты не делаем. Цены услуг показываются клиентам на сайте записи, но деньги система не учитывает.
SMS не используем — уведомления идут в Viber и Telegram.

## Статус

**Готово:**
- [x] **Сайт записи для клиентов** — копия экранов YCLIENTS: мастер с ближайшим временем,
      услуги с поиском и категориями, календарь, «Детали записи». После записи — кнопки
      «Напомнить в Viber / Telegram».
- [x] **Приложение мастера** (ставится на телефон): записи по дням, «Новая», звонок клиенту,
      «пришёл / не пришёл». Уведомления о новых, перенесённых и отменённых записях — push,
      Viber, Telegram.
- [x] **Уведомления клиентам** в Viber и Telegram: подтверждение записи, напоминания за сутки
      и за 2 часа (настраивается), кнопки «Приду» и «Отменить»; сообщения о переносе и отмене.
- [x] **Админка:** журнал записи, услуги, сотрудники, график работы (по дням недели или 2/2),
      клиенты, настройки.
- [x] **Аналитика:** записи по дням, пришли / не пришли / отмены, новые и вернувшиеся клиенты,
      доля онлайн-записей, загрузка мастеров, популярные услуги, дни недели, клиенты, которые
      давно не были, ближайшие дни рождения.
- [x] **Сохранность базы клиентов:** база в PostgreSQL на отдельном томе, ежедневная резервная
      копия (хранится 30 дней, проверено восстановление), выгрузка всей базы в Excel одной кнопкой,
      импорт из Excel/CSV (выгрузка YCLIENTS) без дублей и без перезаписи, клиенты не удаляются.
- [x] Защита от двойной записи на уровне базы, автотесты.
- [x] Демо-версия: GitHub Pages и артефакт.

## Что осталось

1. **Запуск** (когда арендуем сервер): сервер + домен + HTTPS, `docker compose up`, создать
   Telegram- и Viber-ботов, подключить вебхуки, импортировать базу из YCLIENTS, внести реальный
   график, выдать мастерам логины, поставить ссылку записи в Instagram.
2. **Копия базы вне сервера** — раз в сутки отправлять архив в облако (Google Drive / Яндекс Диск
   / S3), чтобы база пережила даже поломку сервера.
3. **Отзывы и рейтинг мастеров** — просьба оценить визит в мессенджере после «пришёл», звёзды
   на сайте записи, как в YCLIENTS.
4. **Фото мастеров** — загрузка прямо в админке.
5. **Рассылки по базе** в Viber/Telegram: «давно не были», поздравления с днём рождения
   (только клиентам с согласием на рассылки).
6. **Лист ожидания** — клиент оставляет заявку на занятый день, при освобождении времени
   ему приходит сообщение.
7. **Журнал действий сотрудников** — кто создал, перенёс или отменил запись.

### Как устроен клиентский сайт YCLIENTS (что повторили)

1. Главная: название салона и три пункта — «Выбрать специалиста», «Выбрать дату и время»,
   «Выбрать услуги». Шаги можно проходить в любом порядке; выбранное показывается в пунктах.
2. Специалисты: «Любой специалист» + список (фото, имя, специализация, рейтинг, кнопка ⓘ
   с описанием), под каждым «Ближайшее время для записи <день>:» и ряд слотов; нажатие на
   слот сразу выбирает мастера и время. Кнопка внизу — «Выбрать услугу».
3. Услуги: поиск, горизонтальные вкладки категорий, список с длительностью, описанием
   («ещё») и ценой («30 – 40 BYN»), чекбоксы; внизу «1 услуга 20 мин. — 20 BYN» и кнопка
   «Выбрать дату и время». Если выбран мастер — только его услуги и его цены.
4. Время: вкладки «<Мастер> / Все специалисты», месячный календарь (недоступные дни серые),
   слоты по 30 минут, сгруппированные «Утро / День / Вечер», кнопка «Готово».
5. Детали записи: мастер, дата и время «18:00 — 18:20», услуги с ценами и «Итого»
   (у каждого блока карандаш для изменения), форма «Имя*», «Телефон*» (+375), «E-mail»,
   «Комментарий», согласия, кнопка «Записаться».

## 1. Как устроен YCLIENTS (справочно)

> Финансы, склад, зарплату и лояльность из этого списка мы сознательно не делаем.

YCLIENTS — это облачная CRM для сферы услуг (с 2023 года входит в VK). Состоит из нескольких продуктов,
которые работают с одной общей базой:

| Продукт | Для кого | Что делает |
|---|---|---|
| Веб-кабинет (yclients.com) | администратор, владелец | журнал записи, клиенты, финансы, склад, зарплата, отчёты, настройки |
| Мобильное приложение YCLIENTS | владелец, мастер | расписание, записи, финансы, склад, KPI с телефона |
| Виджет онлайн-записи | клиент | кнопка «Записаться» на сайте, во ВКонтакте, в Instagram, Яндекс Картах, 2ГИС |
| YPLACES / брендированное приложение | клиент | запись, история визитов, бонусы, абонементы |
| Уведомления | клиент | напоминания и рассылки: push, MAX, ВК, email, SMS, WhatsApp/Telegram через интеграции |
| Маркетплейс интеграций | салон | 100+ интеграций: кассы, телефония, эквайринг, сайты, аналитика |

### 1.1. Модули веб-кабинета

**Журнал записи (главный экран)**
- Сетка: столбцы — мастера (или кабинеты/кресла), строки — время; шаг 5/10/15 минут.
- Вид на день / неделю / 2 недели; фильтры по сотрудникам, услугам, филиалам.
- Создание записи кликом по ячейке, перенос перетаскиванием, растягивание по длительности.
- Статусы визита: ожидается → клиент пришёл → не пришёл / подтвердил → оплачено; цвета записей.
- Групповые записи, перерывы мастера, лист ожидания, повторяющиеся записи.
- В записи: клиент, услуги (несколько подряд), мастер, комментарий, источник записи, оплата.

**Клиентская база (CRM)**
- Карточка: ФИО, телефон, email, день рождения, пол, теги/категории, скидка, номер карты,
  комментарии, «запрет онлайн-записи», согласие на рассылки.
- История визитов, суммы, средний чек, любимые мастера/услуги, долги и депозиты.
- Сегменты и фильтры (не был > 60 дней, именинники, VIP и т. п.), RFM-анализ, импорт/экспорт Excel.

**Услуги и сотрудники**
- Категории услуг, цена (фикс или диапазон «от–до»), длительность; разные цена/длительность у разных мастеров.
- Сотрудники: должность, услуги, график работы (смены, шаблоны 2/2, 5/2), фото и описание для онлайн-записи.
- Ресурсы: кабинеты, кресла, аппараты — чтобы две записи не заняли один аппарат одновременно.

**Онлайн-запись**
- Виджет: «пошаговый» (услуга → мастер → время) или «меню»; вариант «любой специалист».
- Подтверждение по SMS-коду, предоплата/депозит, правила (минимальное время до записи, глубина записи).
- Ссылки и кнопки для сайта, ВК, Яндекс Карт, 2ГИС; аналитика (Яндекс Метрика, пиксель ВК).

**Уведомления и маркетинг**
- Автоматические: подтверждение записи, напоминание за N часов, «спасибо за визит» + просьба оценить,
  «давно не были», поздравление с ДР.
- Ручные рассылки по сегментам. Каналы: push, Telegram, MAX, ВК, WhatsApp, SMS, email.
- Отзывы и оценки мастеров после визита.

**Лояльность**
- Скидочные карты, бонусы и кешбэк, накопительные уровни, реферальная программа.
- Абонементы (например, 10 посещений) и подарочные сертификаты (в том числе электронные, с продажей онлайн).
- Акции и промокоды.

**Финансы и касса**
- Приём оплаты: наличные, карта, СБП, бонусы, сертификаты, абонементы; комбинированная оплата.
- Онлайн-касса по 54-ФЗ (чеки), эквайринг, онлайн-чаевые.
- Кассы/счета, движения денег, расходы (аренда, закупки), инкассация, смены.

**Склад**
- Товары (на продажу) и расходники; приход, продажа, списание, инвентаризация, остатки, поставщики.
- **Технологические карты**: к услуге привязан расход материалов (например, 30 мл краски) —
  автоматическое списание при проведении визита.

**Зарплата**
- Схемы расчёта: оклад, % от услуг, % от продаж товаров, фикс за услугу, с вычетом себестоимости
  материалов, KPI, разные ставки для разных услуг. У YCLIENTS — десятки вариантов условий.
- Ведомость за период, авансы, штрафы и премии, выплаты.

**Аналитика**
- Выручка, средний чек, заполненность расписания, возвращаемость клиентов, эффективность мастеров,
  источники записи, остатки склада, отток клиентов. Дашборд владельца.

**Настройки и безопасность**
- Роли и права (владелец, администратор, мастер — каждый видит своё), журнал действий.
- Несколько филиалов/сеть — для нас на старте не нужно, но заложим в модель данных.


## Архитектура и стек

```
 Клиенты                       Сотрудники
 ├─ сайт записи                ├─ админка (журнал, клиенты, аналитика…)
 └─ Viber / Telegram ◄─┐       └─ приложение мастера + Viber / Telegram / push
                       │                 │
                       └──── сервер ◄────┘
                              ├─ PostgreSQL (+ ежедневные копии)
                              └─ напоминания раз в 5 минут
```

| Слой | Выбор |
|---|---|
| Приложение | Next.js 15 + TypeScript, Tailwind CSS |
| База данных | PostgreSQL 16 + Prisma; запрет пересечения записей на уровне БД |
| Уведомления | Telegram Bot API, Viber REST Bot API, Web Push |
| Запуск | Docker Compose: приложение, база, резервное копирование |

Подробности запуска и настройки ботов — в `README.md`.
