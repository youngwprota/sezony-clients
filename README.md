# Sезоны — онлайн-запись, приложение мастера и админка

Собственная замена YCLIENTS для салона «Sезоны». Внутри три части:

| Адрес | Для кого | Что есть |
|---|---|---|
| `/` | клиенты | онлайн-запись как в YCLIENTS: мастер → услуги → дата и время → контакты; подтверждение и напоминания в Viber / Telegram |
| `/master` | мастера | свои записи по дням, отметки «пришёл / не пришёл», уведомления о новых записях (Viber, Telegram, push); ставится на телефон как приложение |
| `/admin` | администратор, владелец | журнал записи, услуги, сотрудники, график работы, клиенты (импорт и выгрузка), аналитика, рассылки, программа лояльности, настройки |
| бот в Telegram / Viber | клиенты | вместо личного кабинета: «Мой статус» (визиты, уровень, скидка, ближайшие записи), отмена записи, подписка и отписка от акций |

Система только про клиентов и записи: деньги, кассы, зарплаты и склад в неё намеренно не входят.

Сотрудники входят через `/login`.

## Стек

Next.js 15 (App Router, TypeScript), Tailwind CSS 4, PostgreSQL 16 + Prisma, Vitest.

## Запуск для разработки

```bash
cp .env.example .env          # заполнить DATABASE_URL и SESSION_SECRET (≥ 32 символов)
npm install
npx prisma migrate dev        # создаёт таблицы
npm run db:seed               # услуги, мастера, демо-график, владелец admin / admin123
npm run dev                   # http://localhost:3000
```

Проверки — см. раздел «Тесты» ниже.

`npm run db:seed` переносит каталог салона (13 категорий, 131 услуга, 12 мастеров и их
персональные цены) из `prisma/seed-data.json`, создаёт демо-график пн–сб 09:00–21:00 на 3 недели
и владельца `admin`. Пароль владельца можно задать через `SEED_ADMIN_PASSWORD`. Повторный запуск
ничего не перезаписывает.

## Запуск на сервере

```bash
cp .env.example .env    # SESSION_SECRET, APP_URL, POSTGRES_PASSWORD, SEED_ADMIN_PASSWORD, токены ботов
docker compose up -d --build
docker compose exec app npm run setup:webhooks   # подключить ботов к сайту
```

Поднимаются три контейнера: приложение (порт 3000), база PostgreSQL и резервное копирование.
Перед приложением нужен HTTPS (например, Caddy или nginx + Let's Encrypt): без него не работают
вебхуки ботов, push-уведомления и установка приложения мастера на телефон.

## База клиентов: как она сохраняется

- **Хранение.** База PostgreSQL лежит на отдельном томе Docker (`pgdata`) и переживает
  перезапуск и обновление приложения. Клиентов в программе удалить нельзя — только изменить.
- **Ежедневная копия.** Контейнер `backup` раз в сутки делает полную копию базы в папку
  `./backups` на сервере и хранит последние 30 дней. Восстановление:
  `gunzip -c backups/sezony-ДАТА.sql.gz | docker compose exec -T db psql -U sezony sezony`.
  Папку `backups` стоит дополнительно копировать с сервера (на компьютер или в облако).
- **Выгрузка в Excel.** «Клиенты» → «Скачать базу (.xlsx)»: все клиенты с телефонами,
  датами рождения, заметками, числом визитов и датой последней записи. Все ячейки — текст:
  имя вида «=ФОРМУЛА()», введённое на сайте, не выполнится в Excel, а номер не станет числом.
- **Импорт.** «Клиенты» → «Импорт»: файл .xlsx или .csv, например выгрузка из YCLIENTS.
  Дубли по номеру телефона не создаются, имеющиеся данные не перезаписываются.
  Строки с несуществующим номером пропускаются, и программа показывает, какие именно.

## Уведомления

| Кому | Что | Каналы |
|---|---|---|
| Мастеру | новая запись, перенос, отмена | Viber, Telegram, push в приложении |
| Клиенту | подтверждение записи, напоминание за сутки и за N часов (настраивается), перенос, отмена; кнопки «Приду» и «Отменить» | Viber, Telegram |

Клиент подключает мессенджер одной кнопкой на экране «Вы записаны!», мастер — в своём приложении.
Постоянному клиенту, который уже подключён, подтверждение приходит сразу.
Напоминания и поздравления проверяются каждые 5 минут, очередь рассылок — каждые 10 секунд, всё внутри сервера; отключить — `BACKGROUND_JOBS=off`.

**Telegram.** Создать бота у @BotFather, вписать `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`,
придумать `TELEGRAM_WEBHOOK_SECRET`.

**Viber.** Создать бота на partners.viber.com, вписать `VIBER_AUTH_TOKEN` и `VIBER_BOT_URI`
(часть ссылки `viber://pa?chatURI=…`). Viber пишет человеку только после того, как он нажал
«Получать уведомления» в чате с ботом — бот предлагает это сам при первом открытии.
Важно: Viber-боты платные. По условиям Viber (help.viber.com, «Bot commercial model») —
около 100 € в месяц за бота плюс оплата каждого сообщения, которое бот отправляет первым
(напоминания — как раз такие); ответы в течение 24 часов после сообщения клиента бесплатны.
Telegram-бот бесплатный. Если Viber не нужен — просто не задавайте `VIBER_*`, кнопки Viber исчезнут.

**Push в приложении мастера.** `npx web-push generate-vapid-keys` → `NEXT_PUBLIC_VAPID_PUBLIC_KEY`
и `VAPID_PRIVATE_KEY`. На iPhone push работает только у приложения, добавленного на экран «Домой».

После заполнения токенов: `npm run setup:webhooks` (в Docker — `docker compose exec app npm run setup:webhooks`).

## Лояльность и рассылки

Личного кабинета у клиента нет: клиент — это номер телефона, а его «кабинет» — бот. После записи
клиент подключает Telegram или Viber, и бот узнаёт его по чату: команда «Мой статус»
(`/status`) показывает визиты, уровень, скидку и ближайшие записи, `/promo` и `/stop` —
подписка и отписка от акций (в Viber — кнопки и слова «статус», «акции», «стоп»).

**Программа лояльности** («Лояльность» в админке) — без денежного учёта:
- уровни по числу визитов со статусом «Пришёл» (по умолчанию «Новый клиент», «Постоянный» от 5
  визитов −5%, «VIP» от 15 визитов −10%); уровни, пороги, скидки и бонусы настраиваются;
- личная скидка в карточке клиента важнее скидки уровня;
- уровень и скидка видны в журнале (★ на записи и значок в карточке записи), в приложении мастера
  и в списке клиентов — скидку применяют при оплате на месте;
- автоматическое поздравление с днём рождения в 11:00 (включается там же).

**Рассылки** («Рассылки» в админке):
- аудитория: уровень, «не были дольше N дней», «были за последние N дней», число визитов,
  мастер, категория услуг, день рождения в этом месяце, канал; до отправки видно, сколько
  клиентов подходит и скольким сообщение дойдёт;
- получают только клиенты с согласием на рассылки и подключённым мессенджером; при двух
  мессенджерах выбирается Telegram (он бесплатный); в каждое сообщение добавляется способ отписаться;
- `{имя}` и `{скидка}` подставляются в текст, можно добавить кнопку «Записаться»;
- отправка идёт из очереди (~15 сообщений в секунду), по каждой рассылке видно, кому доставлено,
  кому нет и почему; отправку можно остановить.

Согласие на рассылки клиент даёт галочкой при онлайн-записи или кнопкой в боте; администратор
может отметить его в карточке клиента. Рассылки в Viber оплачиваются Viber за каждое сообщение.

## Тесты

| Команда | Что проверяет | Что нужно |
|---|---|---|
| `npm test` | логика без базы: телефоны, время, свободные окна, напоминания, лояльность, импорт, проверки ввода | ничего |
| `npm run test:integration` | запись (в т. ч. одновременные запросы), админка, бот, вебхуки, напоминания, рассылки, вход, выгрузка | PostgreSQL с базой `sezony_test` |
| `npm run test:e2e` | браузер: запись клиента, админка, приложение мастера — на телефоне и на компьютере | PostgreSQL с базой `sezony_e2e` |
| `npm run typecheck` | типы TypeScript во всём проекте | ничего |
| `node scripts/load-test.mjs http://localhost:3000` | нагрузка на публичную часть | запущенный сервер |

Подготовка баз для тестов (один раз):

```bash
createdb -O sezony sezony_test && createdb -O sezony sezony_e2e
DATABASE_URL=postgresql://sezony:sezony@localhost:5432/sezony_test npx prisma migrate deploy
```

Другие адреса баз — через `TEST_DATABASE_URL` и `E2E_DATABASE_URL`.

## Проверка телефонов

Номера проверяются по официальной нумерации (библиотека libphonenumber), а не по количеству цифр:
- принимаются любые привычные формы: `29 123-45-67`, `8 029 1234567`, `+375 (29) 123-45-67`;
- мобильные коды Беларуси — 25, 29, 33, 44, причём только реально выдаваемые диапазоны
  (например, `25 1…` — нет);
- на сайте записи — только мобильные (на них приходят напоминания), в админке и при импорте
  допустимы и городские;
- номер другой страны пишется с «+» и проверяется по правилам этой страны;
- на каждую ошибку — понятное сообщение: «нет такого кода оператора», «короткий», «длинный».

## Надёжность и безопасность

- Пересечение записей одного мастера запрещено самой базой данных: при одновременных
  запросах проходит только один, при «любом мастере» второй клиент получает другого свободного.
- Онлайн-запись принимает только активные услуги, открытые для записи, и только даты в пределах
  «запись открыта на N дней»; на один номер — не больше 3 предстоящих онлайн-записей.
- Вход: после 5 неверных попыток — растущая пауза; смена пароля или удаление доступа мастера
  сразу закрывает его сеансы на всех устройствах.
- Вебхуки ботов проверяют секрет (Telegram) и подпись (Viber); заблокировавший бота клиент
  автоматически отвязывается.
- Все формы проверяются на сервере, сообщения об ошибках — на русском; несуществующие
  страницы и сбои показывают понятную страницу вместо технической ошибки.

## Как устроено

- `src/lib/availability.ts` — расчёт свободных окон (смены минус записи), покрыт тестами.
- `src/lib/booking.ts` — каталог, свободные даты и время, создание онлайн-записи.
- `src/lib/notify.ts`, `src/lib/messengers.ts` — уведомления мастерам и клиентам, Viber и Telegram.
- `src/lib/reminders.ts`, `src/lib/reminder-schedule.ts` — напоминания клиентам.
- `src/lib/analytics.ts` — показатели для страницы «Аналитика».
- `src/lib/loyalty*.ts` — уровни и скидки; `src/lib/segment-rules.ts`, `src/lib/campaigns.ts` — аудитория и очередь рассылок.
- `src/lib/bot.ts` — команды бота («Мой статус», подписка на акции).
- `src/lib/jobs.ts` — фоновые задачи: напоминания, поздравления, очередь рассылок.
- В БД стоит ограничение `Appointment_no_overlap`: у мастера физически не может быть двух
  пересекающихся активных записей, даже если два клиента нажали «Записаться» одновременно.
- Время хранится в UTC, показывается в часовом поясе салона (`Europe/Minsk`, меняется в настройках).
- Состояние онлайн-записи хранится в адресе страницы (`?staff=…&services=…&at=…`), поэтому
  ссылку на конкретного мастера или услугу можно разместить в Instagram.
