# Sезоны — онлайн-запись, приложение мастера и админка

Собственная замена YCLIENTS для салона «Sезоны». Внутри три части:

| Адрес | Для кого | Что есть |
|---|---|---|
| `/` | клиенты | онлайн-запись как в YCLIENTS: мастер → услуги → дата и время → контакты |
| `/master` | мастера | свои записи по дням, отметки «пришёл / не пришёл», уведомления о новых записях (push и Telegram); ставится на телефон как приложение |
| `/admin` | администратор, владелец | журнал записи по мастерам, услуги и цены, сотрудники, график работы, клиенты, настройки |

Сотрудники входят через `/login`.

## Стек

Next.js 15 (App Router, TypeScript), Tailwind CSS 4, PostgreSQL 16 + Prisma, Vitest.

## Запуск для разработки

```bash
cp .env.example .env          # заполнить DATABASE_URL и SESSION_SECRET (≥ 32 символов)
npm install
npx prisma migrate dev        # создаёт таблицы
npm run db:seed               # услуги, мастера, демо-график, владелец admin / admin123
npm run dev                   # http://localhost:3000
```

Проверки: `npm test`, `npm run typecheck`, `npm run build`.

`npm run db:seed` переносит каталог салона (13 категорий, 131 услуга, 12 мастеров и их
персональные цены) из `prisma/seed-data.json`, создаёт демо-график пн–сб 09:00–21:00 на 3 недели
и владельца `admin`. Пароль владельца можно задать через `SEED_ADMIN_PASSWORD`. Повторный запуск
ничего не перезаписывает.

## Запуск на сервере

```bash
cp .env.example .env    # SESSION_SECRET, APP_URL, SEED_ADMIN_PASSWORD, ключи уведомлений
docker compose up -d --build
```

Сайт поднимется на порту 3000; перед ним нужен HTTPS (например, Caddy или nginx + Let's Encrypt).
HTTPS обязателен для push-уведомлений и установки приложения мастера на телефон.

## Уведомления мастерам

**Push в приложении мастера.** Сгенерировать ключи: `npx web-push generate-vapid-keys`, вписать
в `NEXT_PUBLIC_VAPID_PUBLIC_KEY` и `VAPID_PRIVATE_KEY`. Мастер открывает `/master` на телефоне,
добавляет на экран «Домой» и нажимает «Включить уведомления». На iPhone push работает только
у приложения, добавленного на экран «Домой» (iOS 16.4+).

**Telegram.** Создать бота у @BotFather, вписать `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME` и
придумать `TELEGRAM_WEBHOOK_SECRET`. Один раз подключить вебхук:

```bash
curl "https://api.telegram.org/bot<TOKEN>/setWebhook" \
  -d url=https://<ваш-домен>/api/telegram/webhook \
  -d secret_token=<TELEGRAM_WEBHOOK_SECRET>
```

После этого мастер нажимает «Подключить Telegram» в своём приложении.

Мастер получает уведомление, когда к нему записываются (онлайн или через админку), когда запись
переносят и когда её отменяют.

## Как устроено

- `src/lib/availability.ts` — расчёт свободных окон (смены минус записи), покрыт тестами.
- `src/lib/booking.ts` — каталог, свободные даты и время, создание онлайн-записи.
- В БД стоит ограничение `Appointment_no_overlap`: у мастера физически не может быть двух
  пересекающихся активных записей, даже если два клиента нажали «Записаться» одновременно.
- Время хранится в UTC, показывается в часовом поясе салона (`Europe/Minsk`, меняется в настройках).
- Состояние онлайн-записи хранится в адресе страницы (`?staff=…&services=…&at=…`), поэтому
  ссылку на конкретного мастера или услугу можно разместить в Instagram.
